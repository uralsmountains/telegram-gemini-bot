# 🤖 Telegram-бот с напоминаниями и периодическими уведомлениями

Современный асинхронный Telegram-бот на **Python (aiogram 3.x)**, с сохранением в **SQLite** и фоновым планировщиком задач **APScheduler**.

---

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Введите название для бота (например: `Мой Помощник`).
4. Введите юзернейм (должен заканчиваться на `bot`, например: `my_super_reminder_bot`).
5. Скопируйте полученный API токен (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

---

### 2. Установка зависимостей

Откройте терминал в папке проекта и выполните:

```powershell
cd reminder_bot
py -m pip install -r requirements.txt
```

---

### 3. Настройка токена

Откройте файл `.env` в папке `reminder_bot` и укажите ваш токен:

```env
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

---

### 4. Запуск бота

```powershell
py main.py
```

---

## ✨ Возможности бота

- 🕒 **Пошаговое создание напоминания**: кнопка *«➕ Создать напоминание»* с интерактивными кнопками быстрого выбора времени (`Через 10 мин`, `Через 1 час`, `Сегодня в 20:00`, `Завтра в 09:00`, `Каждый день в 09:00`).
- ⚡ **Быстрые команды**:
  - `/remind 15m Заварить чай`
  - `/remind 2h Сделать перерыв`
  - `/remind 19:30 Позвонить другу`
  - `/remind 26.10 14:00 Прийти на встречу`
- 📋 **Управление списком задач**: просмотр активных напоминаний и удаление в один клик.
- 💾 **Надёжность**: все напоминания сохраняются в локальной базе SQLite (`reminders.db`), поэтому они не пропадут даже при перезапуске бота или компьютера.
- 🔁 **Повторяющиеся уведомления**: поддержка ежедневных периодических напоминаний.
